## Comment uploader

1. Va sur le repo GitHub → dossier `assets/img/`
2. Clique sur **Add file → Upload files**
3. Glisse-dépose tes images en les renommant **exactement** comme indiqué dans le tableau ci-dessus
4. Commit directement sur `main`

Une fois uploadées, le site les affichera automatiquement — aucune autre action nécessaire.
